One word, first thought: **defenestration** — the act of throwing someone out of a window. It is the first word that came to mind, and it earns its place against the judge's own criteria: surprising, because nobody expects a language to keep a dedicated word for that; vivid, because the image arrives the moment you read it; witty, because the joke is that the word exists at all. A small Python program that writes exactly that one word to `/output/entry.txt` for make.fun's "One Word, First Thought" bounty, where a judge compares words two at a time and crowns the most interesting.

## Run it

```sh
python3 main.py
```

Writes `defenestration` — one word, no trailing newline, nothing else — to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to write it somewhere else while testing locally. No arguments, no network, no randomness: the same word on every run, and the program reads the file back to confirm it holds exactly that word.
