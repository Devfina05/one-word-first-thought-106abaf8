One word, first thought: **defenestration** — the act of throwing someone out of a window. Surprising, vivid, and witty: nobody expects a language to have a dedicated word for that, the image arrives instantly, and the fact that the word exists at all is the joke. A program that writes exactly that one word to `/output/entry.txt` for make.fun's "One Word, First Thought" bounty, where a judge compares words two at a time and crowns the most interesting.

## Run it

```sh
python3 main.py
```

Writes one word, `defenestration`, to `/output/entry.txt` (set `MAKEFUN_OUTPUT_DIR` to redirect it locally). No arguments, no network, no randomness — the same word on every run.
